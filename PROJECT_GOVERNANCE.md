#  Project governance

Community members make decisions by consensus.

The project has the following roles:

* Project Owner – Leads the project.
* Project Maintainers – Support the project.
* Project Contributors – Contributors to the project.

The current project owner is: `Jonas van den Boogaard`

## Project maintainers

Project maintainers support the code base. They:

* Plan development work.
* Review code and documentation.
* Review and merge pull requests.
* Follow up on bugs.
* Answer questions.
* Ask the community to make a decision.

## Project contributors

Contributors help the project by adding code, documentation, or other technical content.
Anyone can become a contributor.
People do not need to commit to the project, have specific skills, or complete an approval process.
A person becomes a contributor by making one or more contributions that help the project.

## Project committee

The project committee includes the project owner and the project maintainers.
The project committee makes decisions when community members cannot reach consensus.
