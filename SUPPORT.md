# Contact the project

There are a few ways to connect to the ospo-code-scanner project:

* Submit an issue
* Email the Technical Steering Committee: ospo@alliander.com.

## Ask for help, suggest a feature, or give recommendations

If you have problems installing, building, or when using the software, and do not think it is a bug, ask a question in the repository's Issues tab.
If you have ideas for new features or suggestions to improve existing features or documentation, share them in the Issues tab.

## How to report a bug

Use GitHub Issues to report bugs or suggest improvements.
The available templates will help you create your report.

## How to report a security vulnerability

If you found a potential vulnerability in this project, email ospo@alliander.com to responsibly share it.

## Contribute to the project

Visit [CONTRIBUTING.md](CONTRIBUTING.md) to make a project contribution.
